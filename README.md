## Aim
To develop a customer registration form using HTML and Node.js, implement form submission and validation, and store the submitted customer details in a MongoDB database.

## Description
This experiment demonstrates the development of a customer registration form using HTML, Node.js, and Express.js. It collects customer details such as name, password, age, mobile number, email, gender, state, and skills. The submitted information is processed by the server and stored in MongoDB. The stored customer records can also be retrieved and displayed on the webpage.

## Technologies Used
- HTML5
- JavaScript
- Node.js
- Express.js
- MongoDB

## Files
- `index.html` – Customer registration form and display of registered customers.
- `app.js` – Handles form submissions and MongoDB operations.
- `package.json` – Project dependencies and scripts.
- `.env` – MongoDB connection configuration.

## Procedure
1. Create an HTML customer registration form with the required input fields.
2. Set up a Node.js project and install Express and MongoDB dependencies.
3. Connect the Node.js application to MongoDB.
4. Use Express.js to handle form submissions.
5. Validate the submitted customer details and store them in MongoDB.
6. Retrieve and display the registered customer details on the webpage.

## Output
The TechZone customer registration form accepts customer details and submits them to the Node.js server. The details are stored in MongoDB and displayed on the webpage.

## Result
Thus, the customer registration form was successfully developed using HTML, Node.js, and Express.js. Customer details were submitted, stored in the MongoDB database, and retrieved for display on the webpage.
